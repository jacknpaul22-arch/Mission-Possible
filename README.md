## Dynamic launch sequence
The launch now runs through five phases (pad, ascent, orbit, deep space, destination) driven by `launch-sequence.json`, with rocket-specific staging and contextual crew dialogue. See `docs/DYNAMIC_LAUNCH.md`. Validate with `node tests/validate-sequence.js`.
